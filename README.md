# Java OOP programs: fundementals, intermediate level excersises part 2
A structured collection of Java assignments designed to practice 2D array manipulation, core OOP principles (interfaces, inheritance, composition), method overloading, and console-based management systems.
# Exercises Breakdown
# Exercise 1: Mayoral Election Statistics (App1.java)
Processing election data stored in a 2D array to calculate total votes, compute percentages, determine an outright winner (>50%), or identify the top two runoff candidates.  
# Exercise 2: Shape Interface Implementation (App2.java)
Implementing a Shape1 interface within a Rectangle1 class to calculate geometric area and format property strings.  
# Exercise 3: Method Overloading Calculator (App3.java)
Implementing method overloading in a Calculator class to support summing two integers, three integers, two doubles, or an array of integers.  
# Exercise 4: Book & Author Composition (App4.java)
Demonstrating object composition (has-a relationship) by linking an Author object to a Book class with custom constructors and toString() methods.  
# Exercise 5: Shape Hierarchy & Inheritance (App5.java)
Extending a base Shape class to create Rectangle and Triangle subclasses, calculating areas and overriding display behaviors.  
# Exercise 6: Date & Customer Classes (myDate.java, Customer.java)
Designing encapsulated data models for a custom calendar date (myDate) and a Customer containing embedded date objects.  
# Exercise 7: Array-Based Customer List Manager (CustomerList.java)
Implementing a fixed-size 1D array container of Customer objects featuring insertion, code-based search, and batch listing operations.  
# Exercise 8: Interactive Customer Management CLI (App6.java)
Building a console-driven, loop-based menu interface to interactively insert, look up, and display customer records.
